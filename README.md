# Software Design & Implementation

A technical portfolio of object-oriented software design, Java implementation, UML modeling, persistence, and scenario-based verification.

## Projects

### [Lodging Reservation Management System](projects/lodging-reservation/)
**Java 21 · Gson · JSON · Object-oriented design · Automated scenarios**

An implemented Java model for managing accounts and lodging reservations, including subtype-specific pricing, lifecycle validation, global reservation-number uniqueness, JSON persistence, and custom exceptions. The source and standalone verification harness are included. The original implementation passed 635 assertions across 26 scenarios; the reorganized portfolio build requires a fresh validation run.

### [Art Inventory & Transaction Management](projects/art-management/)
**UML · StarUML · Domain modeling**

An object-oriented design study covering an abstract art hierarchy, polymorphic shipping calculations, transaction lifecycle modeling, aggregation, cardinality, and custom exceptions. Native design artifacts are pending publication review. This is **not** presented as an implemented Java application.

## Engineering principles
Requirements analysis · Separation of concerns · Encapsulation · Inheritance · Polymorphism · Domain validation · File persistence · Testable behavior.

## Provenance and scope
These case studies originated in an educational setting and have been curated for technical portfolio presentation. They are not production deployments or commercial client deliverables. The historical academic repository remains private.
