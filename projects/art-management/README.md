# Art Inventory & Transaction Management — UML Design

An object-oriented **design study** for an art inventory and transaction system. The model demonstrates an abstract `Art` superclass, specialized `Painting`, `Drawing`, `Print`, and `Sculpture` subclasses, shipping calculation overrides, constructor overloading, transaction state and inventory responsibilities, customer relationships, and custom exceptions.

**Status:** Native StarUML design only. No Java implementation is claimed.

The native model and diagram will be added from the final verified design after a publication-safety and licensing review. This directory is a placeholder until those artifacts are reviewed.
